# 한국어 AI 티 패턴

판정 에이전트와 재작성 단계가 같이 쓰는 목록이다. ID는 판정 결과에 그대로 적는다. 강도는 S1(하나만 보여도 고친다), S2(몰려 있으면 고친다), S3(다른 신호와 같이 있을 때만)이다. 기계적으로 잡을 수 있는 것은 `phrases-ko.tsv`에도 들어 있어 `score.py`가 센다.

이 목록은 판정용이다. 쓸 때는 이 목록을 피하려고 애쓰지 말고, 예시 글을 흉내 내는 데 집중한다. 금지어를 피하려다 동의어로 돌려 막으면 그것도 AI 티다.

## R. 조수 말투 (가장 먼저 걷는다)

지시 튜닝이 남긴 흔적이다. 탐지기가 가장 강하게 반응하는 층이다.

| ID | 강도 | 패턴 | 사람이라면 |
|---|---|---|---|
| R1 | S1 | 모든 주장에 반대편을 붙여 균형을 맞춘다. "물론 ~도 있지만", "한편으로는 ~, 다른 한편으로는" | 한쪽 편을 든다. 반론은 진짜 필요할 때 한 번 |
| R2 | S1 | 끝에서 다시 정리한다. "결론적으로", "요약하면", "이처럼", "이렇듯" | 마지막 할 말을 하고 그냥 끝낸다 |
| R3 | S1 | 독자를 안내한다. "다음과 같다", "크게 세 가지로 나눌 수 있다", "살펴보자" | 바로 본론 |
| R4 | S1 | 빠짐없이 다룬다. 질문에 없던 측면까지 다 훑는다 | 하고 싶은 말 두세 개만. 나머지는 버린다 |
| R5 | S2 | 단정 대신 완곡을 겹친다. "~할 수 있을 것으로 보인다", "~라고 할 수 있다" | 아는 건 단정, 모르는 건 "잘 모르겠다" 한 번 |
| R6 | S2 | 친절한 마무리. "도움이 되길 바란다", "함께 고민해 보자" | 없다 |
| R7 | S2 | 모든 문장의 무게가 같다. 중요한 말과 사소한 말이 같은 길이, 같은 톤 | 중요한 건 길게 파고, 사소한 건 한 줄로 넘긴다 |

## A. 번역투

| ID | 강도 | 패턴 | 고침 |
|---|---|---|---|
| A1 | S2 | `~을 통해`, `~을 통하여` | `~으로`, 동사로 풀기 |
| A2 | S2 | `~에 대해`, `~에 대한` | 목적격 조사 |
| A3 | S2 | `~에 있어서`, `~에 있어` | `~에서`, 삭제 |
| A4 | S2 | `~에 의해`, `~로 인해` 수동 | 행위자를 주어로 |
| A5 | S1 | `되어진다`, `~지게 된다` 이중 피동 | `된다` |
| A6 | S2 | 사물 주어 + `보여준다`, `제공한다`, `가져온다`, `야기한다` | 사람을 주어로, 평범한 동사로 |
| A7 | S2 | `가지고 있다`, `~을 가진` | 형용사, `있다` |
| A8 | S3 | `그`, `그녀`, `그것`, `그들` 반복 | 이름 반복이나 생략 |
| A9 | S2 | `~에서의`, `~으로의`, `~와의` 이중 조사 | 풀어 쓰기 |
| A10 | S2 | 왼쪽으로 길게 늘어지는 관형절 ("~하고 ~한 ~인 사람") | 문장 둘로 |

## D. 상투 관용구

| ID | 강도 | 패턴 |
|---|---|---|
| D1 | S1 | `시사하는 바가 크다`, `주목할 만하다`, `의미 있는 시사점`, `중요한 역할을 한다` |
| D2 | S1 | `~할 때다`, `~할 시점이다`, `~하는 이유다`, `앞으로의 과제`, `향후` 결말 공식 |
| D3 | S1 | `단순히 A가 아니라 B`, `A를 넘어 B`, `A에서 B로` 대구 (한 편에 한 번 넘으면) |
| D4 | S2 | `중요한 것은 ~이다`, `핵심은 ~이다`, `문제는 ~라는 점이다` 분열문 |
| D5 | S2 | 죽은 비유: 청사진, 적신호, 경고등, 나침반, 초석, 첫걸음, 여정, 지평, 뿌리내리다, 꽃피우다 |
| D6 | S2 | 무생물 의인화: `기술이 묻는다`, `시대가 요구한다`, `데이터가 말해준다` |
| D7 | S2 | 부풀리기 형용사: 획기적인, 혁신적인, 다양한, 풍부한, 깊이 있는, 효과적인, 필수적인, 핵심적인 |
| D8 | S2 | 만능 동사: 강화하다, 구축하다, 확대하다, 도모하다, 제고하다, 극대화하다, 활용하다 |
| D9 | S3 | 감탄 시작: "좋은 질문이다", "흥미로운 주제다" |

## C. 구조와 서식

| ID | 강도 | 패턴 |

| C4 | S2 | 셋 묶기. 형용사 셋, 예시 셋, 명사구 셋이 습관처럼 나온다 |

## K. 쉼표와 띄어쓰기 (KatFishNet 근거, 한국어에서 가장 강한 신호)

| ID | 강도 | 패턴 | 사람 기준 |
|---|---|---|---|
| K1 | S1 | 연결어미 뒤 쉼표: `-고,` `-며,` `-지만,` `-면서,` `-아서,` `-는데,` | 거의 안 찍는다 |
| K2 | S1 | 문두 접속부사 뒤 쉼표: `그러나,` `따라서,` `또한,` `즉,` `특히,` | 안 찍는다 |
| K3 | S2 | 쉼표 있는 문장이 절반을 넘는다 | 에세이 기준 4문장에 1개꼴 |
| K4 | S3 | 띄어쓰기가 너무 완벽하다 (`할 수 있다`, `것 같다`가 매번 규범대로) | 가끔 붙여 쓴다. typo.py가 넣는다 |

## W. 낱말 고르기

| ID | 강도 | 패턴 | 사람이라면 |
|---|---|---|---|
| W1 | S2 | 쉬운 우리말이 있는데 한자어를 고른다. `활용한다`, `존재한다`, `진행한다`, `상이하다`, `야기한다`, `지속적으로` (목록은 `hanjaeo-ko.tsv`) | `쓴다`, `있다`, `한다`, `다르다`, `일으킨다`, `꾸준히`. KatFish 기준 AI는 사람보다 6배 넘게 쓴다 |
| W2 | S2 | 억지 순화. 전문 용어나 굳은 말까지 우리말로 바꿔 어색해진다 (`전극`을 `전기 끝`으로, `확산`을 `퍼짐`으로) | 전문 용어, 고유명사, 우리말이 더 어색한 자리는 한자어 그대로 |
| W3 | S1 | 동의어 돌려 막기. 같은 대상을 `리튬 이온 전지`, `해당 전지`, `이 배터리`, `리튬 기반 이차전지`처럼 문장마다 다르게 부른다 | 처음 쓴 말을 그대로 다시 쓴다. 사람은 같은 단어를 되풀이하는 걸 꺼리지 않는다 |
| W4 | S2 | 같은 뜻을 말만 바꿔 두 번 말한다. "효율이 오른다. 즉 더 적은 힘으로 더 많은 일을 한다" | 한 번만 말한다 |

## L. 결핍 쪽 (고치다 생기는 반대 문제)

|---|---|---|
