# 예시 글 저장소

재작성 단계와 `local_draft.py`가 흉내 낼 사람 글을 둔다. "AI처럼 쓰지 마라"는 금지보다 "이 사람처럼 써라"는 모방이 훨씬 잘 듣는다.

## 어디서 왔나

`scripts/fetch_exemplars.py`가 받아 고른다. 모두 ChatGPT 공개(2022년 11월) 이전 글이라 사람이 쓴 것이 확실하다. 파일별 출처와 라이선스는 `SOURCES.md`에 있다.

| 파일 | 출처 | 쓰는 곳 |
|---|---|---|
| `katfish-논설문-고등-*`, `katfish-논설문-중등-*` | KatFish 데이터셋, 2021년 학생 논설문 원문 | 논설문, 자기소개서, 감상문, 에세이 |
| `katfish-초록-*` | KatFish 데이터셋, 논문 초록 | 보고서, 탐구 글 |
| `namu-설명-*` | 나무위키 2022-03-01 덤프 (CC BY-NC-SA 2.0 KR) | 설명문, 블로그 |

- KatFish 글은 학생이 쓴 원문이라 띄어쓰기 실수가 그대로 있다. 고치지 않는다.
- KatFish 데이터는 라이선스가 표기돼 있지 않다. 그래서 저장소에 넣지 않고(`.gitignore`) 설치할 때 받는다.
- 실존 인물 문서와 신문 기사를 옮겨 적은 듯한 글은 받을 때 거른다.

## 직접 넣기

장르가 맞는 사람 글이 더 필요하면 `장르-번호.md`로 직접 넣어도 된다. 2022년 11월 이전 글이어야 한다. AI가 쓰고 사람이 고친 글은 넣지 않는다.
